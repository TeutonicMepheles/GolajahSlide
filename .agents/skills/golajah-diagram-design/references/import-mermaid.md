# Import Mermaid into GolajahSlide

## Contract

The Mermaid definition remains inside the deck Markdown. The editorial HTML is
the geometry/style source and the generated SVG is the delivery artifact.

```text
Mermaid fence -> safe IR -> editorial HTML -> build extraction -> SVG + sidecar -> inline deck SVG
```

Use this metadata inside the Mermaid fence's `@slide` block:

```yaml
renderer: diagram-design
source: assets/order-flow.diagram.html
src: assets/order-flow.svg
detail: faithful
audience: mixed
min-font-size: 28
safe-margin: 40
```

- `source` must be a local `.html` file containing one primary inline SVG.
- `src` must be a local `.svg` path. It is generated by `--render-diagrams`.
- `detail` is `faithful`, `balanced`, or `simplified`; default to `faithful` so
  an aesthetic redraw does not silently change meaning.
- `audience` is `engineer`, `mixed`, or `executive`; default to `mixed`.
- The build records hashes for the Mermaid definition and authored HTML. A
  normal build fails when either has changed without regenerating the SVG.

## Safe extraction

Run `scripts/mermaid_extract.py` against `.mmd`, `.mermaid`, or Markdown input.
It supports `flowchart`, `sequenceDiagram`, `stateDiagram-v2`, and `erDiagram`.
It parses bounded text only and never renders Mermaid, executes JavaScript,
follows click targets, or fetches a URL.

Use its nodes, edges, fragments, notes, and discarded-directive counts as the
fidelity baseline. Do not copy source coordinates, colors, fonts, or Mermaid's
automatic routing.

## Fidelity

For `faithful`, retain every distinct node, relationship, fragment, and entity
field that fits at the Slide type scale. Above the practical density ceiling,
split the content rather than shrinking it.

For `balanced` or `simplified`, report:

```text
Detail: balanced · 12 source nodes -> 8 drawn
Merged: workers 1–4 -> "Worker ×4"
Dropped: unconnected migration note
Kept in full: request -> validation -> storage path
```

## Authoring requirements

- Put all SVG styles inside the SVG; outer page CSS is not exported.
- Use no `foreignObject`, remote font import, external image, or script.
- Keep the HTML as the only hand-edited drawing artifact. The build owns the
  `.svg` and `.diagram-build.json` files.
